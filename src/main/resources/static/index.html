📖 Como Funciona a Integração Frontend ↔ Backend

1. Como o frontend realiza uma requisição HTTP?

O JavaScript utiliza a API nativa fetch() com funções assíncronas (async/await). A requisição é disparada pela porta 8080 para o backend Spring Boot em http://localhost:8080/album.

2. Verbos HTTP implementados e utilizados:

  • POST /album: Envia os dados do formulário serializados em JSON no corpo (Body) da requisição para cadastrar um novo álbum.
  • GET /album?nome=...: Envia o nome do álbum por parâmetro de URL (Query Param) para buscar um registro específico.
  • GET /album/todos: Recupera a lista completa de todos os álbuns cadastrados no PostgreSQL.
  • PUT /album?id=...: Envia os dados atualizados no corpo (Body) e o ID na URL para modificar um álbum existente.
  • DELETE /album?nome=...: Envia o nome por parâmetro para remover o registro do banco de dados.

3. Como o backend processa e responde?

O AlbumController recebe a requisição, delega as regras para o AlbumService, que utiliza o AlbumRepository (Spring Data JPA / Hibernate) para persistir ou consultar a tabela album no PostgreSQL. Ao concluir, o Spring responde com status HTTP correspondente (200 OK) e dados em JSON quando aplicável.
